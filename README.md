## Cómo probar y dejar feedback

1. **Ver el prototipo:** Haz clic en **Abrir** para probar la herramienta con los casos precargados de 1 clic o con tus propios datos.
2. **Guía de entrada (`?guia=1`):** Explica en menos de 30 segundos qué formato de foto, video o búsqueda espera cada prototipo.
3. **Dar feedback (`?feedback=1`):** Abre directamente el cuestionario breve de validación (3 preguntas puntuales en escala uniforme + comentario opcional anónimo).
